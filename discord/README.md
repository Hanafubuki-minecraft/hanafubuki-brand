# discord/

Готовые сообщения для Discord-сервера Hanafubuki в формате [Discohook](https://discohook.app) — отправляются через вебхук канала, от имени «Hanafubuki» с логотипом, без ботов.

| Файл | Канал |
|---|---|
| [`info.json`](info.json) | информация о сервере: баннер, как зайти, ссылки, что есть, команды |
| [`rules.json`](rules.json) | правила: общие, сервера, Discord |
| [`application.json`](application.json) | заявка на проходку: анкета и как всё проходит |
| [`news.json`](news.json) | первое сообщение в канале новостей: что здесь будет |

Тексты — из [`../INFO.md`](../INFO.md); меняешь там — обнови и здесь.

## Как отправить

1. В Discord: **Настройки канала → Интеграции → Вебхуки → Новый вебхук → Копировать URL**.
2. Открой [discohook.app](https://discohook.app).
3. В редакторе открой **JSON Editor**, замени всё его содержимое на содержимое нужного `.json` (это одно сообщение, без обёрток) и сохрани.
4. Вставь URL вебхука в поле **Webhook URL** и нажми **Send**.

Чтобы потом **отредактировать** уже отправленное сообщение, в Discohook есть *Message link*: вставь ссылку на сообщение, поправь и нажми **Edit** — сообщение обновится без нового поста.
