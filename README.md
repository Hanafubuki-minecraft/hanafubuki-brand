# Hanafubuki: логотип и иконки

Цветок сакуры, с которого ветер срывает лепестки. «Ханафубуки» (花吹雪) значит «метель из лепестков».

## Что где

| Файл | Куда |
|---|---|
| `export/logo/hanafubuki-logo-*.png` | Основной логотип, прозрачный фон: сайт, README, баннеры |
| `export/logo/hanafubuki-logo-dark-*.png` | Основной логотип на тёмном фоне: аватарка GitHub-организации, соцсети |
| `export/discord/hanafubuki-discord-icon-512.png` | Иконка Discord-сервера (Discord сам обрежет в круг) |
| `export/discord/preview-circle-256.png` | Превью, как иконка выглядит в Discord |
| `export/minecraft/server-icon.png` | Иконка сервера Minecraft, строго 64×64. Кладётся в корень сервера рядом с `server.properties` |
| `export/minecraft/preview-x8.png` | Та же иконка в 8 раз крупнее, для просмотра |
| `export/github/hanafubuki-banner.png` | Баннер профиля GitHub-организации (2560×800) |

## Чем версии отличаются

- **Основной**: полная детализация (тычинки, прожилки, штрихи ветра), лепестки улетают вправо-вверх.
- **Discord**: чат-стикер на тёмном фоне, как у основного логотипа. Белая «вырубка» вокруг, как у стикеров в мессенджерах, плоские цвета, тёмный контур, тень, у цветка мордочка. Всё важное внутри круга, читается даже в 48 px.
- **Minecraft**: отдельный упрощённый рисунок под 64×64. Крупный цветок, швы между лепестками, без тонких линий. Собирается в пиксель-арт без сглаживания с ограниченной палитрой, как текстуры в игре.

## Как редактировать

Исходники лежат в `src/`. Это обычный SVG: открываются в Inkscape и Figma, а можно править прямо в текстовом редакторе.

- **Цвета**: блок `<style>` в начале каждого файла; цвета лепестка в `<linearGradient id="petalGrad">`.
- **Форма лепестка**: `<path id="petal">`. Он один, а цветок и улетающие лепестки на него ссылаются, так что правка формы меняет всё сразу.
- **Положение, размер, поворот**: атрибут `transform="translate(x,y) scale(s) rotate(deg)"` у нужного `<use>`.
- **Мордочка в иконке Discord**: три строки после `<circle class="center"`, удали их, если не нужна.
- **Палитра пиксель-арта Minecraft**: список `MC_PALETTE` в `build.py`.

## Сборка картинок

```bash
pip install cairosvg pillow
python3 build.py
```

Все PNG в `export/` пересоберутся из исходников.

## Применить на сервере

Оформление и последние версии плагинов ставятся одной командой (сервер остановлен):

```bash
curl -fsSL https://raw.githubusercontent.com/Hanafubuki-minecraft/hanafubuki-brand/main/server/apply.sh | bash
```

Подробнее — [`server/README.md`](server/README.md).
